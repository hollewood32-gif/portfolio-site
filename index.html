About

Ragdoll Fling

A 30-second browser physics game. Grab the ragdoll, fling it into the walls, and chain hits into combos for big damage. Then try to get your initials on the online leaderboard.

  • TypeScript
  • Matter.js
  • HTML Canvas
  • Vite
  • Cloudflare Workers
  • Cloudflare D1
  • GitHub Actions
  • Vitest
  • Physics and game feel. The ragdoll is rigid bodies joined together. Damage scales with impact speed, quick hits build a combo multiplier, and every hit gets floating numbers, screen shake and sound. Works with a mouse or a touchscreen.
  • CI/CD pipeline. Every pull request runs lint, type-check, tests and a build, and gets its own preview link. Merging deploys to staging automatically; production deploys the same build only after I approve it. I proved the gate works by opening a pull request with a deliberately broken test: merging was blocked.
  • Online leaderboard. A small API on Cloudflare Workers backed by a D1 (SQL) database. The pipeline runs database migrations before each deploy. The server validates every score, rejects impossible ones and rate-limits submissions. It stores only 3-letter initials, the score and the date.
  • Infrastructure as code. Hosting, custom domains and both environments are defined in the repo, not clicked together in a dashboard.
